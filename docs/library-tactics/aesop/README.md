# Aesop のタクティクス

Aesop は、論理の分解・簡単化・補題の適用を組み合わせて証明を探索するパッケージである。mathlib の依存にも含まれるが、提供元がわかるよう独立した一覧に置く。

| ページ | 何をするか |
| --- | --- |
| [aesop・aesop?](aesop.md) | 証明を探索してゴールを閉じる。`aesop?` は証明のタクティクス列も提案する |
| [規則の追加](rules.md) | `add` と `@[aesop ...]` で探索に使う補題を登録する |

各例は `import Aesop` を明示している。Aesop は登録された規則を利用するため、mathlib を追加でインポートした場合は探索に使える規則も変わり得る。

論理の短い証明を自動化するところから始め、同じ補題の適用を繰り返す場合に規則の追加を検討する。数値計算や多項式には [mathlib の専用タクティクス](../mathlib/README.md)もある。

[依存の準備・検証状況](../README.md#例の実行と検証)を確認してから例を実行する。
