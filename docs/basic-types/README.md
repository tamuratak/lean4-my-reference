# 基本データ型の日本語リファレンス

Lean に標準で用意されているデータ型について、何を表すか → 値をどう作るか → 中身をどう使うかを短い具体例で説明する。

## データ型と型クラスの区別

`List` と `Option` は、型を受け取ってデータ型を作るものであり、型クラスではない。例えば、`List Nat` は自然数のリストの型、`Option Nat` は自然数の値があるかないかを表す型である。

一方、`ToString` や `BEq` は型クラスであり、その型の値を文字列に変える操作や、値を比較する操作などを要求する。例えば `[ToString α]` は、`α` の値を文字列に変える実装をインスタンス探索で補うための引数である。仕組みは [`class`・`instance`](../syntax/class.md)を参照。

| 書き方 | 意味 |
| --- | --- |
| `xs : List Nat` | `xs` は自然数のリストというデータ |
| `x : Option Nat` | `x` は自然数があるかないかを表すデータ |
| `[ToString α]` | `α` の値を文字列に変える実装を要求する引数 |

## コレクションを選ぶ目安

| 型 | 保持するもの | 順序・重複 |
| --- | --- | --- |
| `List α`・`Array α` | 要素の列 | 並び順と重複を保持する |
| `Vector α n` | 長さがちょうど `n` の列 | 並び順と重複を保持し、長さを型で指定する |
| `Std.HashMap α β` | キーごとの値 | 同じキーへの登録は更新、列挙順は前提にしない |
| `Std.HashSet α` | 要素の有無 | 重複を数えず、列挙順は前提にしない |
| `Std.TreeMap α β` | キーごとの値 | 同じキーへの登録は更新、比較関数に従う順序 |
| `Std.TreeSet α` | 要素の有無 | 重複を数えず、比較関数に従う順序 |

## 対象と検証

対象は `lean-toolchain` が指定する Lean 4.35.0-rc3 である。各 `lean` コードブロックは独立した完成例で、そのまま実行できる。標準ライブラリのインポートが必要な例では、ブロック内に `import` を明記する。mathlib などの追加ライブラリは不要である。

```sh
python3 scripts/check_examples.py docs/basic-types/*.md
```

記法そのものは[文法要素の一覧](../syntax/README.md)、記号からの検索は[記号索引](../symbols.md)を参照。

参照：[公式リファレンス：Basic Types](https://lean-lang.org/doc/reference/latest/Basic-Types/)。
