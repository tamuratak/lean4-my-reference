# 仮定から証明を取り出す `‹…›`

`‹P›` は、現在の仮定から、型が `P` に合う証明を取り出す記法である。仮定の名前を指定する代わりに、必要な型を指定する。

```lean
example (P : Prop) (hp : P) : P := ‹P›
```

この例では `hp : P` があるので、`‹P›` は `P` の証明になる。`show P by assumption` に相当する。

証明を組み立てる式の一部としても使える。

```lean
example (P Q : Prop) (hp : P) (hq : Q) : Q ∧ P := ⟨‹Q›, ‹P›⟩
```

外側の `⟨…⟩` は論理積の証明を作り、内側の `‹…›` は仮定から各証明を取り出す。見た目が似ているが、役割は異なる。

`‹_›` は、必要な型を周囲の式から推論する。

```lean
example (P : Prop) (hp : P) : P := ‹_›
```

これは `by assumption` に相当する。合う仮定がなければ失敗し、仮定や定理を組み合わせて証明を探索するわけではない。同じ型の仮定が複数ある場合、名前でどれを選ぶか指定できないので、特定の証明を使いたいなら `hp` のように名前を書く。

タクティクスとしてゴールを閉じる操作は [assumption](../tactics/assumption.md)、値や証明を構築する山括弧は [⟨…⟩](anonymous_constructor.md) を参照。

参照：[公式 API：タクティクスと `‹…›` の記法](https://lean-lang.org/doc/api/Init/Tactics.html)。
