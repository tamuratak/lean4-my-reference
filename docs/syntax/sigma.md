# 依存ペア型：`Σ`

`Σ x : α, β x` は、**`α` 型の値 `x` と、`β x` 型の値を組にする型**である。依存ペア型、依存和型、シグマ型とも呼ぶ。ここで「依存」とは、**２番目の成分の型が、１番目の成分の値によって決まる**という意味である。

`Σ` は型を表す記法であり、実際のペアの値は `⟨x, y⟩` で作る。追加の `import` は不要である。

## 普通のペアとの違い

普通のペア `Nat × String` では、１番目の自然数が何であっても、２番目の型は `String` である。

一方、`Σ n : Nat, Fin n` では、１番目に選んだ `n` に応じて、２番目の型が `Fin n` になる。`Fin n` は、`n` 未満の自然数を表す型である。

`Fin n` の作り方と数値リテラルの注意点は、[有限範囲の自然数](../basic-types/fin.md)を参照。

| ペアの型 | １番目の成分 | ２番目の成分の型 |
| --- | --- | --- |
| `Nat × String` | `3` でも `5` でもよい | 常に `String` |
| `Σ n : Nat, Fin n` | `3` を選ぶ | `Fin 3`（値は 0、1、2） |
| `Σ n : Nat, Fin n` | `5` を選ぶ | `Fin 5`（値は 0、1、2、3、4） |

例えば、上限 `n` と、その範囲内の番号を一緒に保持したいときに使える。単なる `Nat × Nat` では、２番目の数が１番目より小さいことは型に含まれない。

## 値を作る・成分を取り出す

```lean
def bounded : Σ n : Nat, Fin n := ⟨3, ⟨1, by decide⟩⟩

example : bounded.1 = 3 := rfl
example : bounded.2.val = 1 := rfl
example : bounded.2.val < bounded.1 := bounded.2.isLt
```

外側の `⟨3, …⟩` が依存ペアを作る。１番目に `3` を入れたので、２番目には `Fin 3` の値が必要になる。内側の `⟨1, by decide⟩` は、自然数 `1` と、`1 < 3` の証明からその値を作っている。`Fin 3` の値として `4` を入れることはできない。

`.1` で１番目、`.2` で２番目の成分を取り出せる。一般に `p : Σ n : Nat, Fin n` なら、それぞれの型は次のようになる。

```text
p.1 : Nat
p.2 : Fin p.1
```

`p.2.val` は範囲内の自然数そのもの、`p.2.isLt` はその数が `p.1` より小さいという証明である。

パターンで分解しても、成分どうしの型の関係は保たれる。

```lean
def indexValue (p : Σ n : Nat, Fin n) : Nat :=
  match p with
  | ⟨n, i⟩ => i.val

example : indexValue ⟨3, ⟨1, by decide⟩⟩ = 1 := rfl
```

この枝では `n : Nat` と `i : Fin n` が使える。分解後も、`i` は取り出した `n` 未満の数を表す。

## `Sigma` と別の書き方

`β : α → Type` は、`α` 型の値を受け取り、型を返す関数である。`Σ x : α, β x` は `Sigma β` の記法であり、`(x : α) × β x` とも書ける。

```lean
example : (Σ n : Nat, Fin n) = Sigma Fin := rfl
example : ((n : Nat) × Fin n) = (Σ n : Nat, Fin n) := rfl
```

`Nat × String` のように２つの型を並べる `×` と、`(n : Nat) × Fin n` のように１番目の成分に名前を付ける `×` を区別する。後者では、その名前を２番目の型に使える。

## 部分型・存在命題との違い

値と、その値に関係するものをまとめるという点は似ているが、２番目に入るものと用途が違う。

| 型・命題 | まとめるもの | 用途 |
| --- | --- | --- |
| `Σ x : α, β x` | 値 `x` と、`β x` 型のデータ | 関係するデータをペアとして保持する |
| `{x : α // P x}` | 値 `x` と、条件 `P x` の証明 | 条件を満たす値をデータとして保持する |
| `∃ x : α, P x` | 証人 `x` と、条件 `P x` の証明 | 条件を満たす値が存在するという命題を証明する |

通常の `Σ` では `β x` は `Type` のデータ型である。条件の証明を添えたい場合は[部分型](subtype.md)、存在だけを主張したい場合は[存在命題](logical_symbols.md)を使う。上の `Fin n` 自体は証明を含むが、依存ペアの２番目に入るのは `Fin n` 型のデータである。

[依存関数型](function_types.md) `(x : α) → β x` は、入力 `x` を受け取り、それに応じた型の値を返す**関数**を表す。依存ペア型 `Σ x : α, β x` は、選んだ `x` と、それに応じた型の値を保持する**ペア**を表す。

ここでの `Σ` は型を表しており、数値の総和を計算する記号ではない。
