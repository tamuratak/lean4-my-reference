# Lean における命名の慣習

Lean のコードでは、変数や仮定の名前に、読者が役割を読み取りやすくするための慣習がある。ただし、Lean の文法として、型や命題を表す専用の文字が決まっているわけではない。

## 変数と仮定の命名の慣習

Lean の標準ライブラリや Lean の解説にある短い例・一般的な定理では、次のような名前をよく使う。名前は役割を推測する手がかりであり、実際の役割は宣言された型や式の文脈で確認する。

| よく使われる名前 | 典型的な役割 | 宣言の例 |
| --- | --- | --- |
| `α`、`β`、`γ` | 型の変数 | `α : Type` |
| `x`、`y`、`a`、`b` | 型に属する値 | `x : α` |
| `n`、`m` | 自然数 | `n : Nat` |
| `f`、`g` | 関数 | `f : α → β` |
| `P`、`Q`、`p`、`q` | 命題、または述語 | `P : Prop`、`P : α → Prop` |
| `h`、`hp`、`hP`、`hx` | 仮定として受け取った証明や、途中で得た証明 | `hp : P`、`hx : P x` |

mathlib は Lean で書かれた数学ライブラリであり、`α` を型、`h` や `hx` を証明の名前に使う慣習は mathlib にも見られる。一方、数学の分野や扱う対象に応じた名前も使われる。例えば、代数では `R` を環、`K` を体、`M` を加群、`V` をベクトル空間の型の名前に使うことがある。Lean 全体で見られる慣習に加えて、ライブラリや分野ごとの命名にも注意が必要である。

## 型の名前と値の名前

`α` や `β` は、具体的な型を固定しない定義によく使われる。

```lean
def mapValue {α β : Type} (f : α → β) (x : α) : β := f x

example : mapValue Nat.succ 2 = 3 := rfl
```

`α` は入力の型、`β` は出力の型、`f` は関数、`x` は入力の値である。`mapValue Nat.succ 2` では、`α` と `β` はどちらも `Nat` と推論される。

ギリシャ文字すべてが型の名前に使われるわけではない。数学の文脈では、ギリシャ文字を角度や実数のパラメータなどの値の名前に使うこともある。また、型の変数に `A` や `T` などの名前を使ってもよい。

## 命題の名前と証明の名前

`P : Prop` は命題を表し、`hp : P` は命題 `P` の証明を表す。`hp` や `hP` という名前は、「`P` に関する仮定・証明」という対応を読者に伝えるための慣習である。

```lean
example (P Q : Prop) (hp : P) (hq : Q) : P ∧ Q := by
  exact ⟨hp, hq⟩
```

仮定 `hp : P` と `hq : Q` を組み合わせると、ゴール `P ∧ Q` の証明が得られる。`hp` の代わりに `h` や `proofOfP` と名付けても、型が `P` であれば同じように証明として使える。

`P : α → Prop` の場合、`P` は値を受け取って命題を返す述語である。証明の型は `P` そのものではなく、`P x` などになる。

```lean
example {α : Type} (P : α → Prop) (x : α) (hx : P x) : ∃ y, P y := by
  exact ⟨x, hx⟩
```

`x` は型 `α` の値、`hx` は「`x` が性質 `P` を満たす」という命題 `P x` の証明である。`hx` は `x` 自体の証明という意味ではない。例えば `hx : x ≠ 0` や `hxy : x = y` のように、値や条件に対応した名前を付けることも多い。

## 慣習と型の指定の違い

`α` という名前だけで型になったり、`h` で始まる名前だけで証明になったりすることはない。次の例も文法上・型検査上は有効である。

```lean
example (α : Nat) (hp : Nat) : Nat := α + hp

example (T : Type) (value : T) : T := value

example (P : Prop) (proofOfP : P) : P := proofOfP
```

最初の例では、`α` も `hp` も自然数の値である。役割の確認には、名前に加えて `: Nat`、`: Type`、`: P` などの型の情報が必要になる。普段は、慣習に沿った名前や内容を表す名前を選ぶと、読み手が役割を把握しやすい。
