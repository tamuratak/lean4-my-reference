# 属性：`@[…]` の日本語リファレンス

`@[simp]`・`@[instance]` など、宣言に追加の扱いを指定する**属性**を説明する。各ページはこのディレクトリの直下に置く。

## 文法・コマンド・タクティクスとの関係

`@[…]` 自体は、宣言に属性を付ける**構文**である。属性は、簡単化に使う定理の登録や、定義をどこで展開するかの設定などを行う仕組みであり、名前ごとに働きが違う。

`@[simp]` はタクティクスではない。定理を簡単化の規則に登録する属性であり、`by` の中で簡単化を実行する `simp` がタクティクスである。また、既存の宣言に属性を付ける `attribute` はコマンドである。

このリファレンスでは、属性の働きを調べやすくするため、[文法要素](../syntax/README.md)・[確認用の `#` コマンド](../commands/README.md)・[タクティクス](../tactics/README.md)と別の分類にまとめる。

## 似た記法との区別

| 記法 | 意味 |
| --- | --- |
| `@[simp] theorem ...` | 次の宣言に属性を付ける |
| `attribute [simp] theoremName` | 既存の宣言に属性を付ける |
| `[ToString α]` | 関数などのインスタンス引数 |
| `@f` | 関数の暗黙引数も明示して渡すための記法 |
| `#[1, 2, 3]` | 配列の値 |

`@` や角括弧が共通していても、これらは別の記法である。
