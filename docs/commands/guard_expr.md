# `#guard_expr`

`#guard_expr e = e'` は、**二つの式が定義上同じになるかを検査する**コマンドである。成功した場合は通常、何も表示しない。

```lean
#guard_expr (2 + 3 : Nat) = (5 : Nat)
```

この例は自然数の具体的な計算を比較している。

既定の `=` は、積極的に展開する定義を中心とした判定である。通常の `def` も展開して比較する場合は `=~` を使う。

```lean
def plusZero (n : Nat) : Nat := n + 0

#guard_expr plusZero =~ (fun n : Nat => n)
#guard_expr (fun n : Nat => n + 0) =~ (fun n : Nat => n)
```

このように関数の式どうしも比較できる。ただし、展開の範囲によって結果が違い、上の `n + 0` を含む関数も既定の `=` では一致の検査に通らない。

定理を使って等式を書き換えたり、帰納法で証明したりするコマンドではない。例えば、加算の交換則が成り立っていても、それだけで二つの式が定義上同じになるわけではない。

比較の仕方を指定する変種もある。

| 指定 | 何を比較するか |
| --- | --- |
| `=` | 展開しやすい定義を中心に、定義上の等しさを確認 |
| `=~` | 通常の定義の展開も許して、定義上の等しさを確認 |
| `=ₛ` | 型を確認した後の式の構造が一致するかを確認 |
| `=ₐ` | 束縛変数の名前の違いを除き、式の構造が一致するかを確認 |

ここでの `=` などは、このコマンドの比較方法を指定する記号である。ソースコードの文字列そのものを比較するわけではない。

[`#guard`](guard.md) は条件を実行して検査する。`#guard_expr` は式の一致を検査する。`by` 内の対応する操作は[タクティクスの検査のページ](../tactics/guard_target.md)を参照。

参照：[公式 API：`#guard_expr`](https://lean-lang.org/doc/api/Init/Guard.html#Lean.Parser.Command.guardExprCmd)。
