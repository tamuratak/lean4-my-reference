# `#exit`

`#exit` は、**その位置でファイルの後続の処理を打ち切る**コマンドである。

```lean
#check (3 : Nat)
#exit
```

`#check` の型の情報を表示した後、処理を打ち切ったことを示す警告が出る。

開発中のファイルで、前半だけを確認したい場合に使える。

```text
前半の宣言や確認コマンド
#exit
後半の宣言や証明
```

この形では後半は確認されない。ファイルにエラーが出なかったとしても、後半の証明まで Lean が検証したことにはならない。

`#exit` は `IO` プログラムの終了命令でも、`by` の中のゴールを閉じるタクティクスでもない。ファイルの処理を途中で止めるためのコマンドである。

完成したファイル全体を確認する際には、打ち切る位置が残っていないかを確認する。

参照：[公式 API：`#exit`](https://lean-lang.org/doc/api/Lean/Parser/Command.html#Lean.Parser.Command.exit)。
