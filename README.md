# Lean の日本語リファレンス

自分で読み返して理解できることを重視した、Lean 4 の日本語リファレンス。

目的に応じて、次の一覧から読む。

- [文法要素の一覧](docs/syntax/README.md)：宣言、式、型、名前空間など、Lean のコードの読み方と書き方。
- [標準タクティクスの一覧](docs/tactics/README.md)：仮定やゴールを操作する証明の命令。

文法要素は `docs/syntax/`、タクティクスは `docs/tactics/` に分ける。各ページはそれぞれのディレクトリ直下に置き、分類は一覧の中で行う。

説明は短い具体例を中心にし、例は Lean 4.34.1 で検証する。対象のバージョンは `lean-toolchain` を参照。

文法要素とタクティクスの例をまとめて検証するには、リポジトリのルートで次を実行する。

```sh
python3 scripts/check_examples.py
```
